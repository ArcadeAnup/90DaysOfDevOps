Day 16 of #90DaysOfDevOps.

Today I containerized both a Django app and a Node.js app using Docker. Starting to see how containers make applications portable and consistent across environments.

Also learned about optimizing Docker images using:

* Multi-stage builds
* Distroless images

The size difference was honestly insane. Same application, massively smaller image. Faster pulls, reduced attack surface, and better deployment efficiency.

One of those days where Docker stopped feeling like “just another tool” and started making architectural sense.
