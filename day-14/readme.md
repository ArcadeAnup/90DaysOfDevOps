# Day 14: Docker and Labs


Today I actually used Docker instead of just reading about it.
Containerized a Python app, wrote a Dockerfile from scratch, built the image, ran it locally, and pushed it to DockerHub. The whole workflow finally makes sense now that I've done it end-to-end.
Also did Docker labs on KodeKloud to test what actually stuck vs what I just understood conceptually. Had to figure things out without tutorials holding my hand. That's where actual learning happens.
Biggest takeaway: Labs need to be a daily thing. Reading and following tutorials feels like progress, but it's not the same as being dropped into a problem and having to solve it yourself. That's the difference between knowing Docker commands and actually understanding Docker.
