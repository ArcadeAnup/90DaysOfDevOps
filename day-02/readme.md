# 🖧 Networking Fundamentals

## What is Networking?
Networking is the sharing of data and resources between devices.

A device connected to a network is called a **Host**.
Examples:
- PC
- Server
- Mobile device

---

# 🌍 Types of Networks

## LAN (Local Area Network)
A network within a small geographical area like:
- Home
- School
- Office

## WAN (Wide Area Network)
A network spread across larger distances.

Examples:
- Internet
- Leased lines

---

# 🔀 Networking Devices

## Router
A router connects different networks together and forwards data between them.

## Switch
A switch connects multiple devices inside the same network.

### Types of Switches
- Manageable Switch
- Unmanageable Switch

## Modem
Modem stands for:
- Modulation
- Demodulation

It converts:
- Analog signals ↔ Digital signals

---

# 🌐 IP Addressing

## IPv4
- 32-bit address
- Example: `192.168.1.1`

## IPv6
- 128-bit address
- Created because IPv4 addresses are limited

# 📡 TCP/IP & OSI Model

I learned about:
- OSI Model
- TCP/IP Model
- How data travels through different layers

### OSI Layers
1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

# 🚚 TCP vs UDP

## TCP
- Reliable
- Connection-oriented
- Uses acknowledgements

## UDP
- Faster
- No acknowledgements
- Less reliable

# 📚 DevOps Case Studies

Today I also studied DevOps case studies and learned how engineering culture and deployment practices directly impact companies.

## Netflix
Netflix uses strong DevOps practices such as:
- Continuous Deployment
- Automation
- Monitoring
- Scalable cloud infrastructure

This allows them to deploy updates rapidly while maintaining reliability for millions of users.

## Knight Capital Group
Knight Capital Group suffered one of the biggest deployment failures in history because of poor deployment practices and lack of proper safeguards.

A faulty software deployment caused massive unintended stock trades, leading to losses of around **$440 million in less than an hour**.

This case showed me:
- Why testing matters
- Why automation matters
- Why rollback systems matter
- Why DevOps is not optional in modern software engineering

One bad deployment can literally destroy a company. Software engineers accidentally discovering financial terrorism through bad CI/CD pipelines. Remarkable species.

# 📝 Key Takeaways

- Networking is the backbone of communication between systems.
- IP addressing and protocols are essential for internet communication.

- DevOps practices improve reliability, speed, and deployment safety.
- Poor deployment processes can lead to catastrophic failures.
